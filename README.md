# ux-writing-kaio

Claude-Skill zum Schreiben und Verbessern von Texten nach UX-Writing-Prinzipien (klar, prägnant, hilfreich, gesprächshaft, markenkonform) im Stil des Kantons Bern. Sprache: Deutsch, Schweizer Rechtschreibung.

## Inhalt

- `ux-writing-kaio/SKILL.md`: der Skill (Ablauf, Briefing, sechs Prinzipien, Schreibweise, Kanalvorgaben, Microcopy, Glossar, Checkliste)

## Verwendung

Den Ordner `ux-writing-kaio/` als Skill in Claude hinzufügen (Claude.ai: Einstellungen → Skills; Claude Code: `~/.claude/skills/`).

## Hinweis

Inhalte müssen fachlich geprüft werden. Die Verantwortung liegt bei der Person, die den Text verwendet. Dies ist kein offizielles Angebot des Kantons Bern.
